# Reserva Natural

Proyecto académico desarrollado en SQL Server para la administración de reservas naturales.

## Características
- Gestión de parques naturales
- Registro de visitantes
- Gestión de especies
- Áreas protegidas
- Personal administrativo
- Personal de vigilancia
- Entradas a parques
- Relaciones ecológicas

## Tecnologías
- SQL Server
- T-SQL
- Git
- GitHub
